## 📖 Project Description

**PEAK** is a full-stack fitness web application that helps users manage their health goals by offering tools to track workouts and meals, create a personal profile, and find nearby gyms. The app tailors the experience based on user input to support consistent and personalized progress.

---

## 🚀 Features

- 🔐 User Registration & Login 
- 🏋️ Access to structured Workout Routines & Exercise Tutorials
- 🗺️ Nearby Gym Locator using Google Maps API
- 📈 Track Exercise Progress and Log Meals
